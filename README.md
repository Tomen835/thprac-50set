## RUEEE thprac Fork for 50 Set Practice

A fork of RUEEE thprac with an added counter to automatically track deaths/resets for 50 sets.

New line added to the ingame overlay which always tracks deaths and resets.

## How to Use

Turn on the in game overlay from the backspace menu. The counter will be running at all times automatically.

The reset and capture counts both increment upon retry. The capture count then decrements on death afterwards. Therefore you should only die at most once during resets otherwise the capture counter gets messed up. 

To reset the counter back to 0/0, just bomb.
